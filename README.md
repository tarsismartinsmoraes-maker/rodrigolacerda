# Rodrigo Lacerda

Site institucional de Rodrigo Lacerda, escritor e palestrante.

## Arquivos

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: visual responsivo e animações.
- `app.js`: menu e animações de entrada dos cards.
- `assets/`: fotografias e capa do livro otimizadas em WebP.

## Visualização local

Com Python instalado, execute na pasta do projeto:

```sh
python -m http.server 4173
```

Abra http://localhost:4173 no navegador.

## Hospedagem

Site estático, sem instalação de dependências ou etapa de build. Publique a pasta raiz em uma hospedagem de sites estáticos.

Os botões abrem o WhatsApp de contato. As fontes Montserrat e Open Sans são carregadas pelo Google Fonts. As animações respeitam a preferência por movimento reduzido.
